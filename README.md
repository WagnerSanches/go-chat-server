## O que é o projeto
 
Um chat em Go via TCP (`localhost:4444`) com três programas: o servidor (`server.go`), o cliente (`client.go`) e um bot que inverte o texto (`bot.go`).
Usuários trocam mensagens públicas e privadas e podem mudar de apelido. O protocolo está em `protocolo.md`.
